### Getting started with Noteable



This session is run using a Noteable notebook which contains all the instruction, tasks, and code that you will need. To access the notebook follow the instructions below:



1. Click the Noteable link on the Learn page
2. On the Noteable home page select "Standard Python 3" from the dropdown menu then click "start"
3. Wait for the server to connect (this may take a few minutes)
4. On the menu bar at the top of the screen select "Git" and then select "Clone a Repository" from the dropdown menu
5. Enter the following URL in the box that opens: XXXXX Add GitLab link XXXXXX
6. Click "clone" to load the repository
7. A folder called "PgT-Python-Vibe" will appear in the panel on the left side of the screen
8. Double click "PgT-Python-Vibe" then double click "chemistry\_python\_intro.ipynb" to open the notebook
9. For the rest of the session work through the instructions and tasks in the notebook



If you have any trouble accessing Noteable or opening the notebook ask one of the demonstrators for help
